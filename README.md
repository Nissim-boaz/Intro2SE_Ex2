# מודול נוכחות Web חכם (Smart Attendance Web Module)

מערכת רישום נוכחות Web מודרנית ואקדמית המבוססת על סריקת קודי QR דינמיים, אימות Google OAuth, בדיקת טווחי רשת קמפוס (IP CIDR), ולוח בקרה בזמן אמת למרצה.

---

## 🚀 תכונות עיקריות

- **F1: ניהול סשנים גנרי**: תמיכה בסשן יחיד פעיל בכל רגע נתון. המרצה פותח סשן (עם זמן ברירת מחדל של 90 דקות) וסוגר אותו ידנית. הישות תוכננה באופן מודולרי וגנרי לשימוש עתידי גם למטלות, שאלונים או הצבעות.
- **F2: קוד QR מתחלף כל 6 שניות**: הברקוד מתחלף אוטומטית כל 6 שניות, עם מד התקדמות ויזואלי למרצה ולסטודנטים.
- **F3: טוקן HMAC ללא שמירה ב-DB**: הטוקן מחושב בזמן אמת מתוך סוד שרת (`HMAC_SECRET`), מזהה הסשן ומספר החלון `int(time / 6)`. טוקן מחלונות קודמים נדחה מידית.
- **F4: עוגייה חתומה (Signed Cookie) ל-5 דקות**: עם סריקה תקינה, השרת מנפיק Cookie חתום באמצעות `itsdangerous` התקף ל-5 דקות. כך תהליך ההתחברות אינו נכשל גם אם ה-QR התחלף במהלך ההזדהות.
- **F5: אימות Google בלבד**: ללא הזנת אימייל ידנית בטופס. השרת מאמת מקומית את ה-ID Token שהתקבל מגוגל באמצעות ספריית `google-auth`.
- **F6: טעינת רשימת סטודנטים מ-CSV**: הקובץ (`data/students.csv`) מכיל עמודות `name,email`. לא ניתן לפתוח סשן אם הקובץ חסר או לא תקין.
- **F7: מניעת כפילויות אטומית**: אינדקס ייחודי `(session_id, email)` ב-SQLite מונע כל רישום כפול. ניסיון נוסף מציג הודעה ברורה ואינו מייצר כפילויות.
- **F8: תיעוד מלא**: שמירת כל השדות: שם, אימייל, שעת רישום, כתובת IP, מזהה דפדפן (User-Agent), סטטוס ואישור מרצה.
- **F9: בדיקת כתובת IP (קמפוס)**: כתובת ה-IP נבדקת מול טווחי ה-CIDR המוגדרים בקונפיגורציה (`.env` ו-`data/campus_ips.txt`). כתובת מחוץ לקמפוס **אינה נחסמת**, אלא מסומנת כ-`suspicious` (חשודה).
- **F10: אישור ידני למרצה**: המרצה יכול לאשר בזמן אמת נוכחות חשודה בלחיצת כפתור אחת, עם תיעוד של שעת האישור המדויקת.
- **F11: סינון משתמשים שאינם ברשימה**: אימייל שאינו מופיע ב-CSV מקבל הודעה ברורה, והניסיון נרשם בטבלת "ניסיונות שנדחו" המוצגת למרצה בדאשבורד.
- **דאשבורד בזמן אמת**:
  - ספירת נוכחים מתעדכנת כל 2 שניות.
  - שעון ספירה לאחור לזמן שנותר בסשן.
  - גרף נוכחות לאורך זמן באמצעות **Chart.js**.
  - סיכום לאחר סגירה (נוכחים, חשודים, ולא הגיעו מתוך ה-CSV).
  - ייצוא דו"ח מלא לקובץ **CSV** עם קידוד UTF-8 התומך בעברית באקסל.

## 📂 מבנה הפרויקט (Architecture)

הפרויקט בנוי ב-Python עם **Flask** המחולק ל-Blueprints עצמאיים:

```
.
├── app.py                     # נקודת כניסה ראשית ומפעל האפליקציה (Application Factory)
├── config.py                  # קריאת הגדרות סביבה (Environment Configuration)
├── gunicorn.conf.py           # קונפיגורציית שרת פרודקשן (4 workers, multithreading)
├── requirements.txt           # תלויות פייתון
├── .env                       # משתני סביבה וסודות מקומיים
├── .env.example               # תבנית משתני סביבה
├── data/
│   ├── students.csv           # רשימת הסטודנטים המורשים בכיתה (name, email)
│   ├── campus_ips.txt         # קובץ הגדרת טווחי IP של הקמפוס (CIDR)
│   └── attendance.db          # בסיס נתונים SQLite (נוצר אוטומטית במצב WAL)
├── database/
│   └── db.py                  # אתחול DB, חיבורים ואינדקסים ב-WAL mode
├── modules/
│   ├── sessions/              # ניהול מחזור חיים של סשנים, טוקני HMAC ו-QR
│   ├── auth/                  # אימות Google ID Token, סיסמת מרצה ומודל Mock לבדיקות
│   ├── attendance/            # סריקת QR, הנפקת עוגייה חתומה ל-5 דק' וקליטת נוכחות
│   ├── campus_check/          # בדיקת כתובות IP מול טווחי קמפוס מוגדרים
│   ├── dashboard/             # דאשבורד מרצה, סטטיסטיקות, אישור חשודים וייצוא CSV
│   └── students/              # קריאת CSV, ולידציה וחישוב סטודנטים שנעדרו
├── static/
│   ├── css/style.css          # עיצוב רספונסיבי מודרני מותאם מובייל (iOS & Android)
│   └── js/
│       ├── lecturer.js        # עדכון נתונים כל 2 שניות, Chart.js וסבב QR כל 6 שניות
│       └── attend.js          # טיימר 5 דקות של ה-Cookie וטיפול בהתחברות Google
├── templates/
│   ├── base.html
│   ├── lecturer/
│   │   ├── login.html         # כניסת מרצה
│   │   ├── dashboard.html     # לוח בקרה פעיל עם QR, גרף וטבלאות
│   │   └── summary.html       # סיכום שיעור סגור
│   └── attendance/
│       ├── attend.html        # מסך נוכחות לסטודנט בנייד
│       └── error.html         # מסך שגיאה אם ה-QR פג תוקף
└── tests/                     # חבילת בדיקות מלאה (pytest)
    ├── test_qr_token.py
    ├── test_campus_check.py
    ├── test_students_csv.py
    ├── test_attendance_flow.py
    └── test_concurrency.py    # בדיקת 60 בקשות במקביל מתחת לשנייה
```

## ⚙️ התקנה והרצה

### 1. הפעלת הסביבה הווירטואלית
```bash
source venv/bin/activate
# במידת הצורך: pip install -r requirements.txt
```

### 2. הגדרת משתני סביבה (`.env`)
הקובץ `.env` כבר מוגדר עם ערכי ברירת מחדל מוכנים לפיתוח:
- סיסמת מרצה: `admin123`
- מצב בדיקות מקומי: `MOCK_AUTH=1` (מאפשר בחירת סטודנטים מה-CSV בלחיצה אחת לצורך הדגמה ובדיקות)
- כאשר מגדירים Google Client ID אמיתי: מגדירים `GOOGLE_CLIENT_ID` ב-`.env` ומעבירים `MOCK_AUTH=0`.

### 3. הרצה מקומית (Development)
```bash
source venv/bin/activate
python app.py
```
השרת יעלה בכתובת: `http://localhost:5050`

### 4. הרצה עם Gunicorn (Production - 4 Workers)
```bash
source venv/bin/activate
gunicorn -c gunicorn.conf.py app:app
```

## 🌐 כתובות וניווט במערכת

- **כניסת מרצה / לוח בקרה**: `http://localhost:5050/lecturer`
  - סיסמה: `admin123`
- **סריקת נוכחות לסטודנט**: `http://localhost:5050/attend?t=<token>`
  (הקישור מופק אוטומטית מתוך קוד ה-QR המוצג בדאשבורד)

## 🧪 הרצת בדיקות אוטומטיות (Tests)

המערכת כוללת חבילת בדיקות מקיפה עם `pytest`:
```bash
source venv/bin/activate
python -m pytest -v
```

הבדיקות מוודאות:
1. `test_qr_token.py`: החלפת טוקן כל 6 שניות ודחיית טוקנים מחלון קודם.
2. `test_campus_check.py`: זיהוי כתובות קמפוס ופילוח כתובות חיצוניות ו-Proxy headers.
3. `test_students_csv.py`: תקינות קובץ ה-CSV, חסימת פתיחת סשן על קובץ פגום וחישוב נעדרים.
4. `test_attendance_flow.py`: תרחיש מלא מקצה לקצה (סשן, עוגייה של 5 דקות, התחברות, סימון חשודים, אישור ידני, דחיית זרים וייצוא CSV).
5. `test_concurrency.py`: עמידה בעומס של **60 סטודנטים בו-זמנית** ללא שגיאות נעילה וזמני תגובה של פחות מ-100ms.
